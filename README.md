# Choice of Collateral Currency in Differential Swaps

Reproduction of selected numerical experiments from Ding, Liu and Rutkowski,
"Choice of Collateral Currency in Differential Swaps".

The paper develops closed-form pricing and hedging results for
collateralised SOFR/€STR differential swaps under a joint Vasicek-Garman-
Kohlhagen cross-currency model, and studies how the choice of collateral
currency (USD vs EUR) affects valuation through (i) a deterministic
collateral-carry channel and (ii) a stochastic quanto correction generated by
the contractual foreign-rate leg. This repository implements the closed-form
formulas (Propositions 4.1, 4.2, Corollary 4.1), an exact-Gaussian Monte Carlo
validation of those formulas, the collateral-currency and quanto value
adjustments of Sections 6.2-6.3, and the discrete futures-hedging strategies
of Proposition 5.2 (Section 6.4).

No external market data is used anywhere in this repository: every numerical
input is the paper's own synthetic baseline parameter set (Section 6.1,
Table 1), and all data (Monte Carlo and Euler-Maruyama paths) are simulated
on the fly from the model.

## Layout

```
src/    Vasicek discount factors and integrated-rate moments (vasicek.py),
        deterministic quanto correction (quanto.py), closed-form swap
        pricing and par margin (pricing.py), exact-Gaussian Monte Carlo
        pricer (mc_simulation.py), discrete futures-hedging simulator
        (hedging.py), and all paper-derived parameters (config.py)
exp/    exp1_mc_validation.py, exp2_collateral_adjustment.py,
        exp3_quanto_adjustment.py, exp4_discrete_hedging.py
tests/  pytest unit tests for every src/ module
results/  Saved metrics (.json/.csv) and static figures (.png), plus RESULTS.md
data/   Empty package: no market data or synthetic-data generator is used
        (every experiment simulates its own paths directly from the model)
```

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

No API keys or external data are required.

## Tests

```bash
python -m pytest
```

## Experiments

Run from the repository root; each script writes its outputs to `results/`.

```bash
python -m exp.exp1_mc_validation
python -m exp.exp2_collateral_adjustment
python -m exp.exp3_quanto_adjustment
python -m exp.exp4_discrete_hedging --full
```

Experiment 4 accepts `--full` to use the paper's 10,000 common Monte Carlo
paths (Section 6.4); this is also the default path count (`EXP4_PATHS_RUN ==
EXP4_PATHS_PAPER = 10,000` in `src/config.py`), since a full vectorised run
completes in well under a minute.

`reproduce.sh` runs the test suite and all four experiments in sequence.

## Results

See `results/RESULTS.md` for the comparison between every reproduced metric
and the paper's reported values, with a verdict for each, and for the
"Deviations from the paper" and "Not reproduced" sections.
